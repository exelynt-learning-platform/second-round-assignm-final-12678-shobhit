# 🛒 E-commerce Backend System (Exelynt Assignment)

Developed a professional-grade backend using **Spring Boot 3** and **MySQL**.

## 🛠 Features Implemented:
- **Security:** JWT Authentication with Role-Based Access Control.
- **Payment:** Integrated **Stripe Gateway** for secure transactions.
- **Cart & Orders:** Managed complex relationships (Many-to-Many) for smooth checkout.
- **Validation:** Robust input validation with custom Error Handling.
- **Quality:** 100% Pass rate in Unit Tests for core services.

## 🚀 How to Run:
1. Create a MySQL database named `ecommerce_db`.
2. Update `application.properties`.
3. Run `mvn spring-boot:run`.

## 🧪 Testing:
- Used Mockito for Unit Testing. Run `mvn test` to verify.
